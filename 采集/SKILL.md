# 短视频评论采集工具

采集短视频公开评论数据，AI 分析用户痛点并生成内容选题建议。

> **合规声明**：本工具仅用于获取平台**公开可见**的评论数据，供内容创作者进行选题分析和用户研究。请遵守相关平台的服务条款及数据保护法规。

## 触发

用户输入 `/采集 <短视频链接>`

## 执行流程

### Step 1 — 运行脚本

- 脚本位于 `C:\Users\Administrator\.agents\skills\采集\采集_comments.py`
- 检查脚本文件是否存在
- 检查 playwright 依赖是否已安装（未安装则执行 `pip install playwright && playwright install chromium`）
- 运行 `python 采集_comments.py <短视频链接>`

### Step 2 — 读取采集结果

- 找到输出的 `comments_{video_id}_{timestamp}.txt` 文件
- 读取全部评论内容

### Step 3 — AI 分析

用以下逻辑分析评论：

① **提取用户痛点**（每类包含：核心描述、情绪指向、证据引用）：
- 哪些问题被反复提及？
- 用户的真实情绪是什么？（焦虑/困惑/渴望/抱怨）
- 有无代表性的用户原话可以引用？

② **生成内容选题**（按共鸣度排序）：
- 哪个痛点最有内容价值？
- 切入角度是什么？
- 选题难度等级（简单/中等/难）

### Step 4 — 输出报告

按以下格式输出到终端：

```
## 📊 数据概览
评论总数：X 条
采集时间：YYYY-MM-DD HH:mm

## 🔍 用户痛点
1. [痛点标题]
   - 表现：……
   - 情绪：焦虑/困惑/渴望
   - 用户原话："……"
   - 提及频次：高/中/低

## 💡 选题建议
1. [难度] 选题标题（共鸣度 X/10）
   - 核心论点：
   - 切入角度：
   - 目标用户：
```
