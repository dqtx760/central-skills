# 原始词云设计来源

用户于 2026-10-03 提供“新建 文本文档.txt”。词云原型为 600×400 像素椭圆，border-radius:50%，使用同色五层 box-shadow：

```css
40px 40px 0 -5px,
80px 10px 0 -10px,
110px 35px 0 -5px,
-40px 50px 0 -8px,
-70px 20px 0 -10px
```

词条使用绝对位置、不同字号和独立旋转。当前模板沿用这五层偏移构造底板，以宽度/785 的单位缩放，并将底板缩入容器预留阴影空间；词条位置由模板计算，字号和角度适配屏幕，旋转包围盒参与碰撞检查。

预览内的 16 个词条只演示视觉排布，不来自真实聊天消息统计；正式模板仍使用待填占位符。不回滚之前的弹窗修复。
