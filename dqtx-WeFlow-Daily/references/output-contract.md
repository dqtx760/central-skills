# 内容与输出约定

用户提供的修复版模板是唯一布局基准，完整保留 CSS、脚本、复选框、目录锚点及页尾联系方式。预览只作参考。原始提示第一行的示例群名不是默认目标群。

## 生成
复制 assets/daily-template.html，填入所有标题、消息数、参与人数、时间、卡片、词云与统计占位内容。不能把所有 [数量] 用同一个值替换：消息数与人数不同。内容不足时减少重复卡片或写“无相关讨论”，不要凑内容。今日未结束标明“截至 HH:mm”；抓取窗口和首末消息时间分别标注。部分记录在页面显眼处注明。
完整版保留热门词云、热议速览、资源分享、答疑建议、消息汇总、精彩金句、数据看板、制作工具。简化版保留词云、最多三个热点、消息汇总、前三级话唠榜及原页尾；删除未使用目录项，使锚点仍有效。

热点为归纳，不冒充原话。金句须有真实原文、发送者和时间；无合适金句明确写无。资源仅来自群消息，链接只允许 http/https 并转义属性。普通文本使用 HTML 转义，禁止插入消息携带的 HTML、script 或事件属性。
精确统计基于该窗口内去重后的成员消息。当天活跃人数不是群总人数。发言榜按稳定发送者 ID；时段分布按上海时间。词云是主题关键词，未实现精确词频时标为“主题关键词”，不用伪造频次。
空日报标明该时间窗口未发现消息，全部统计归零、移除示例条目。采集错误不能生成声称“无消息”的日报。

## 保留修复
词云维持原始五层偏移阴影形成的不规则云朵椭圆轮廓，按容器宽度缩放；词条按重要程度显示不同字号并轻微旋转，旋转后的包围盒也纳入自动碰撞和边界检查；只生成词条文本与类别，不手写位置。建议 12–16 个简短词条，最多 24 个，避免长句；模板自动计算位置并在屏幕变化时重排，极窄屏且词条过密时回退为完整可读的文字布局。公众号与赞赏弹窗以可见视口正中间为基准，禁止改为底部面板；窄屏和低高度时限制卡片高度并允许内部滚动。保留深浅色主题切换、两组复选框状态和链接触发的弹窗结构；链接与 :target 是无脚本回退和三张原始二维码地址、no-referrer 属性，不替换、不重绘二维码。二维码依赖联网；不承诺完全离线显示。

## 验证和交付
运行：python <技能路径>/scripts/check_report.py <日报.html>
脚本检查 CSS/JS 未改、二维码地址、关键交互 ID、无重复 ID、目录目标存在、内容无残留占位符。它不能判断统计或总结是否真实，需回查来源。
浏览器可用时检查窄屏/桌面、长群名、词云换行、目录、主题切换、公众号与赞赏弹窗、关闭及滚动恢复。没有浏览器时明确未完成交互验证。
提供 HTML 文件与消息条数、日期、完整/部分标识。输出目录遵循宿主的持久保存规则；默认不留原始消息文件。文件名过滤 Windows 禁用字符及路径穿越，不覆盖已有日报，必要时加时间后缀。

微信文件预览若把视口报告为整份文档高度，模板用点击的 clientY/screenY 估算可见屏幕位置。这是兼容启发式，不保证所有文件预览器支持；最终效果应在正常浏览器与目标手机上验证。

造型来源与缩放方式见 original-cloud-design.md。不要把云朵背景简化成圆角矩形或单一规则椭圆。
