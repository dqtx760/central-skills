# 微信文件预览兼容修复

用户手机截图中遮罩出现、页面变暗，但卡片未出现在可见区域。根据截图推断：长文档预览器的布局视口与实际手机屏幕不一致，卡片可能定位到可见区域之外；这不是已经确认的微信内部实现结论。

更新：当视口高度明显大于 screen.availHeight 时限制遮罩高度，并用点击 clientY/screenY 差值估算当前屏幕在文档中的位置。正常浏览器仍以 visualViewport 居中。触发入口改为链接，并增加 CSS :target 回退。

增加 8000 像素文档视口、844 像素屏幕、页尾点击与文档底部边界的计算检查。既有模板、二维码不变检查通过。浏览器和手机真机测试仍未完成；启发式无法保证每种文件预览器表现一致。

新增在线模板预览入口，只发布仓库现有占位模板，不包含用户聊天记录。正式群日报保持本地，不会自动公开。
