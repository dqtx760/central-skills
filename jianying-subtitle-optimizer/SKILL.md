# 剪映字幕智能校对技能 (JianYing Subtitle Optimizer)

本技能用于实现**剪映视频字幕的端到端自动化校对与原地写回**。
用户在剪映中完成视频导入与「智能字幕 / 识别文字」后，无需手动复制粘贴文本，直接触发本技能即可自动完成「读取草稿 -> 智能校对 -> 原地加密写回 -> 桌面留档」。

---

## 🎯 触发场景

当用户说以下内容时，必须使用本技能：
- “帮我校对剪映最新视频的字幕”
- “校对剪映字幕”、“剪映字幕纠错”、“优化剪映字幕”
- “读一下剪映草稿的字幕，帮我改一下写回去”
- 斜杠命令：`/jianying-subtitle-optimizer`

---

## 📋 执行 SOP（四步工作流）

### 第一步：读取剪映最新草稿字幕

调用本地 MCP 工具 `get_latest_draft_subtitles`（来自 `jianying-subtitle` MCP 服务）：
```python
# 示例 MCP 调用
res = await tool.get_latest_draft_subtitles()
```

- 若报错或返回空：
  - 检查剪映是否打开并生成了智能字幕；
  - 提示用户：“请确认已在剪映中完成【文本 -> 智能字幕 -> 识别文字】，并将剪映切回左上角首页草稿列表。”
- 获取返回字段：
  - `draft_name`：草稿名称（如 `10月24日`）
  - `total_lines`：字幕总行数
  - `lines`：按时间轴顺序排列的原版字幕文本列表

---

### 第二步：智能校对与纠错规则

对 `lines` 列表中的每一句字幕进行专业校对，遵循以下**四大核心原则**：

1. **【铁律】严格 1 对 1 行数对齐（必须保持总行数相等）**：
   - 校对后的列表长度必须与原列表完全一致（`len(corrected_lines) == len(lines)`）；
   - **严禁擅自合并两行或把一行拆成两行**，否则会导致剪映时间轴上的切片错位！如果原字幕某行为纯语气词（如“呃”），替换为简短承接词或空格，确保行号对准。

2. **清除口语废话与结巴卡顿**：
   - 过滤掉高频口头禅、结巴和多余语气词（如：“这个呃”、“然后呢”、“啊”、“那额度了”、“嗯”、“诶”等）；
   - 保留口播演讲的自然停顿与语势。

3. **专有名词与 AI 模型专业校准**：
   - 结合本机技术上下文（参考用户的模型环境与知识库）纠正 ASR 语音识别错误：
     * `Claude open 十五点五` / `OPPO S5.5` → **Claude Opus 5.5**
     * `GPT6.1SO` → **GPT-6.1-Sol**
     * `workbody的H3` → **WorkBuddy 的 Hy3**
     * `GPT plus` / `Claude的Pro` → **ChatGPT Plus** / **Claude Pro**
     * `FocuSee`、`OpenFilm`、`FaceFusion` 等专业工具名称正字。

4. **语法倒错与口播顺畅度优化**：
   - 修正“审美了很好”为“审美非常好”；
   - 修正“我给他建议”为“我给大家的建议”；
   - 保持口播风格接地气、有网感，不写书面死板套话。

---

### 第三步：原地加密写回剪映草稿并导出桌面

校对完毕后，调用本地 MCP 工具 `update_draft_subtitles`：
```python
res_update = await tool.update_draft_subtitles(
    corrected_lines=corrected_lines,
    draft_name_or_path=draft_name,
    export_to_desktop=True
)
```

- 该工具会自动：
  1. 在剪映项目目录生成 `draft_content.json.bak` 安全备份；
  2. 保持原有毫秒级时间戳不变，只替换文字与样式区间；
  3. 调用 `jy-draftc -ec` 重新加密打包写回剪映；
  4. 在用户桌面（Desktop）生成 `校正字幕_<草稿名>.txt` 与 `.srt` 文件留档。

---

### 第四步：输出成果与对比报告

向用户汇报校对结果，包含：
1. **草稿信息**：项目名称、处理行数、备份文件位置。
2. **核心修正对照表**：列出 5~8 处最关键的识别错误与修正对比（说明修改原因）。
3. **下一步操作提醒**：
   > 💡 **剪映已原地更新完成！**  
   > 请在剪映首页草稿列表中，**重新双击进入该项目**，即可直接看到校正后的字幕与完美对齐的时码！
