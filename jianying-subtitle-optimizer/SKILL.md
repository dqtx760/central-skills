# 剪映字幕智能校对与视觉精排技能 (JianYing Subtitle Optimizer)

本技能用于实现**剪映字幕端到端自动化校对、三层视觉排版与多智能体并行视频包装**。
用户在剪映中完成视频导入与「智能字幕 / 识别文字」后，无需手动复制粘贴文本，直接触发本技能即可自动完成「读取草稿 -> 智能校对 -> 导出 SRT 供并行包装 -> 三层样式排版 -> 安全生成精修工程」。

---

## 🎯 触发场景

当用户提出以下需求时，必须使用本技能：
- “帮我校对剪映最新视频的字幕”
- “校对剪映字幕”、“剪映字幕纠错”、“优化剪映字幕”
- “读一下剪映草稿的字幕，帮我改一下写回去并设置样式”
- 斜杠命令：`/jianying-subtitle-optimizer`

## 🚀 多智能体并行包装协作流 (Parallel AI Pipeline)

为大幅提升出片效率，本技能原生支持**双智能体协同作业**：

```mermaid
flowchart TD
    A[用户在剪映导入视频并点击识别文字] --> B[触发本技能 /jianying-subtitle-optimizer]
```

## 📋 执行 SOP（详细工作流）

### 第一步：无感读取剪映最新草稿

调用本地 MCP 工具 `get_latest_draft_subtitles`（来自 `jianying-subtitle` MCP 服务）：
```python
res = await tool.get_latest_draft_subtitles()
```
- 自动定位最后修改的草稿目录，解密提取字幕列表与时码；
- 取得 `draft_name`、`total_lines`、`lines`、`subtitles`。

---

### 第二步：智能校对与纠错铁律

对提取出的逐行字幕进行专业校准，严格遵循以下四大规则：

1. **【铁律】严格 1 对 1 行数对齐（总行数绝对守恒）**：
   - 校对后的列表长度必须与原列表完全一致（`len(corrected_lines) == len(lines)`）；
   - **严禁擅自合并行或跨行拆分**，确保与剪映时间轴上的每一段原始切片毫秒级对齐！
2. **清除口语废话与结巴卡顿**：
   - 剔除“这个呃”、“然后呢”、“啊”、“那额度了”、“嗯”、“诶”等口癖，保持口播干净自然。
3. **专有名词与 AI 模型专业校准（结合本机环境事实）**：
   - `Claude open 十五点五` / `OPPO S5.5` ➔ **Claude Opus 5.5**
   - `GPT6.1SO` ➔ **GPT-6.1-Sol**
   - `workbody的H3` ➔ **WorkBuddy 的 Hy3**
   - `GPT plus` / `Claude的Pro` ➔ **ChatGPT Plus** / **Claude Pro**
   - 工具名词正字：`FocuSee`、`OpenFilm`、`FaceFusion`、`overlay-studio` 等。
4. **语法倒错纠偏**：
   - 修正听写错序（如“审美了很好” ➔ “审美非常好”、“我给他建议” ➔ “我给大家的建议”）。

---

### 第三步：优先生成桌面 SRT（供并行 AI 助手使用）

校对完成后，第一时间在桌面生成：
* 📄 **`C:\Users\Administrator\Desktop\校正字幕_<草稿名>.srt`**
* 📄 **`C:\Users\Administrator\Desktop\校正字幕_<草稿名>.txt`**

**立即提醒用户**：
> 💡 *“校正后的标准 SRT 字幕已生成至桌面！你现在可以立即把该文件发送给另一个 AI 助手（如调用 `/overlay-fx-generator` 或 `agent-motion`）同步制作透明动效层！”*

---

### 第四步：三层视觉字幕排版与安全写回

根据短视频黄金视觉动线，将草稿升级为**三层立体字幕系统**，并采用**克隆安全副本策略（`create_clone=True`）**避免剪映内存缓存覆写：

| 视觉层级 | 轨道定位 | 字体与样式参数 | 内容规则 |
|---|---|---|---|
| **顶层：头顶标题** | 最顶部 (`y=0.78`) | • 字体：**雅月体** (`85757855`)<br>• 字号：`18.0`<br>• 效果：**花字金光渐变效果**（`[1.0, 0.85, 0.32]` + 深金褐描边 + 微阴影） | 全片贯穿置顶（提炼视频核心吸引点大标题） |
| **中层：胸前重点** | 胸前焦点 (`y=-0.05`) | • 字体：**经典雅黑（经典黑）**<br>• 字号：`19.0`<br>• 效果：**亮黄色高光大字** + 黑色重描边（12.0）+ 独立阴影 | 核心论点卡点弹出（8~10处提神标签，如 `【什么是复利资产？】`、`【Claude 5.5】`） |
| **底层：基础字幕** | 底部常规 (`y=-0.65`) | • 字体：**Aa研宋体** (`4010355`)<br>• 字号：`13.0`（12~15之间）<br>• 阴影透明度：`60%`（`alpha=0.6`）<br>• 阴影模糊度：`6%`（`0.010`）<br>• 阴影距离：`6.0`<br>• 阴影角度：`-60.0°` | **严格每句不超过 8 个字**（若原句较长，按语义拆成 <=8 字的短句并平分时码） |

调用 MCP 写回：
```python
res_update = await tool.update_draft_subtitles(
    corrected_lines=corrected_lines,
    draft_name_or_path=draft_name,
    style_preset="yansong_shadow",
    create_clone=True,
    export_to_desktop=True
)
```
