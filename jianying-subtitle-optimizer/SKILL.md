# 剪映字幕智能校对与视觉精排技能 (JianYing Subtitle Optimizer)

本技能用于实现**剪映字幕的高效智能校对、三层立体视觉排版与音画动效自动搭配**。
用户通过桌面上的「剪映SRT字幕导出」工具一秒复制台词发给智能体，智能体即可自动完成「文本智能纠错 -> 三层样式排版与音画动效注入 -> 安全生成剪映精修草稿」。

---

## 🎯 触发场景

当用户提出以下需求或直接粘贴台词时，必须使用本技能：
- 用户从「剪映SRT字幕导出」点击【📋 复制文本】后，粘贴文本并发起请求：
  * “帮我校对这段剪映字幕”
  * “这是刚导出的字幕文本，帮我校正并编辑样式”
- 斜杠命令：`/jianying-subtitle-optimizer [附带台词文本]`
- （兼容模式）：用户未粘贴文本时说“校对剪映最新草稿”，智能体通过本地 MCP 自动探测最新草稿。

---

## 📋 执行 SOP（核心四步）

### 第一步：获取字幕文本（用户直接粘贴）

1. **主流标准模式（用户主导，1秒完成，零冲突风险）**：
   - 用户打开桌面上的 **`剪映SRT字幕导出`**；
   - 选中目标草稿，点击右下角 **【📋 复制文本】**；
   - 直接将整段台词粘贴在对话中发给智能体。
2. **自动探测模式（备用兜底）**：
   - 若用户未附带文本，调用本地 MCP 工具 `get_latest_draft_subtitles` 自动定位最新草稿并提取字幕。

---

### 第二步：智能校对与纠错铁律

智能体对字幕逐句进行专业校准，严格遵循四大规则：

1. **【铁律】严格 1 对 1 行数对齐（总行数绝对守恒）**：
   - 校对后的列表长度必须与原文本行数完全相等（`len(corrected_lines) == len(lines)`）；
   - **严禁擅自合并行或跨行拆分**，确保每一行对应剪映时间轴上的一个独立字幕切片！
2. **清除口语废话与结巴卡顿**：
   - 彻底剔除“这个呃”、“然后呢”、“啊”、“那额度了”、“嗯”、“诶”等口语碎词，保持呼吸感与节奏感。
3. **专有名词与技术模型专业校准（结合本机事实）**：
   - `Claude open 十五点五` / `OPPO S5.5` ➔ **Claude Opus 5.5**
   - `GPT6.1SO` ➔ **GPT-6.1-Sol**
   - `workbody的H3` ➔ **WorkBuddy 的 Hy3**
   - `GPT plus` / `Claude的Pro` ➔ **ChatGPT Plus** / **Claude Pro**
   - 专业工具正字：`FocuSee`、`OpenFilm`、`FaceFusion`、`overlay-studio` 等。
4. **语法倒错纠偏**：
   - 修正“审美了很好” ➔ “审美非常好”、“我给他建议” ➔ “我给大家的建议”。

---

### 第三步：调整字幕样式与音画动效包装（使用 jianying-editor 规范）

在写回剪映时，严格遵循以下三层视觉排版与音画动效搭配法则：

#### 1. 三层字幕区域视觉规范

| 视觉区域 | 画面定位 | 字体与样式参数 | 字数与排版规范 |
|---|---|---|---|
| **头顶标题字幕区域** | 画面最顶部 (`y = 0.78`) | • 字体：**雅月体** (`85757855`)<br>• 字号：`18.0`<br>• 效果：**花字透明渐变效果**（`[1.0, 0.85, 0.32]` 金光渐变 + 深金褐描边 + 微阴影） | 全片贯穿置顶（提炼视频核心吸引点大标题） |
| **胸前重点字幕区域** | 胸前黄金焦点 (`y = -0.05`) | • 字体：**字由黑皮** 或 **经典黑（经典雅黑）**<br>• 字号：`19.0` ~ `20.0` 大字<br>• 效果：**亮黄色高光大字** + 黑色 `12.0` 重描边 + 独立阴影 | 在 8~10 处核心论点卡点弹出提神（如 `【什么是复利资产？】`、`【Claude 5.5】`） |
| **基础字幕区域** | 底部常规位 (`y = -0.65`) | • 字体：**Aa研宋体** (`4010355`)<br>• 字号：**12-15 之间**（默认 `13.0`）<br>• 阴影透明度：**不超过 60%**（`alpha = 0.6`）<br>• 阴影模糊度：`6%`（`0.010`）<br>• 阴影距离：`6.0`<br>• 阴影角度：`-60.0°` | **每句话不要超过 8 个字**（过长字幕按语义自然拆句分段，并按比例平分时码） |

#### 2. 字幕动画与音效组搭配技巧（核心诀窍）

根据字幕语义与语气节奏，选择合适的动画与音效组合：

| 适用场景与情绪 | 字幕入场动画 | 搭配音效搜索词 | 听觉与视觉协同效果 |
|---|---|---|---|
| **重点数据/价值揭示** | **滚入** (`TextIntro.滚入`) | **「收银叮」** | 数字或关键论点滚入，伴随金币/收银清脆声，突出价值感 |
| **层级展开/知识点梳理** | **折叠** (`TextIntro.折叠`) | 搜 **"展开"** | 画面如卷轴折叠展开，音效跟进，适合步骤讲解 |
| **核心结论/重磅定格** | **缩小** (`TextIntro.缩小`) | **「嘭」** | 从大瞬间缩小定格，强冲击力低音嘭声，适合下定论 |
| **观点转折/下一页翻转** | **翻动** (`TextIntro.翻动`) | **「翻书」** | 页面翻转动效配清脆翻书声，带来阅读节奏感 |
| **快节奏转场/思路切换** | **滑动** (`TextIntro.向左滑动`) | 搜 **"WHOOSH"** | 极速呼啸风声，画面丝滑横滑切换，维持注意力 |
| **细节聚焦/灵感涌现** | **吸入** (`TextIntro.吸入`) | **「水滴」** | 聚光聚焦动效配空灵水滴声，营造思考感 |
| **代码/打字/思考旁白** | **打字机** (`TextIntro.复古打字机`) | 搜 **"typing"** | 文字逐字敲出，配合机械键盘敲击音，科技感拉满 |
| **总结金句/升华时刻** | **日出** (`TextIntro.日出`) | **「叮」** | 画面如日出般升起浮现，配轻灵提示音，金句定格 |

   - 若剪映正处于编辑状态：自动退回主页解除内存文件锁 ➔ 原地加密写回原工程 ➔ 自动重新点击该项目卡片进入；
   - **原项目名 100% 保持不动，零多余文件，零重复工程！**
3. **输出比对报告**：
   - 向用户展示 5~8 处最关键的识别错误与修正对比；
