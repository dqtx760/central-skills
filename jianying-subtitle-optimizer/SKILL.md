# 剪映字幕智能校对与视觉精排技能 (JianYing Subtitle Optimizer)

本技能用于实现**剪映字幕的高效智能校对、三层立体视觉排版与音画动效自动搭配**。
用户通过桌面上的「剪映SRT字幕导出」工具一秒复制台词发给智能体，智能体即可自动完成「文本智能纠错 -> 三层样式排版与音画动效注入 -> 安全生成剪映精修草稿」。

---

## 🎯 触发场景

当用户提出以下需求或直接粘贴台词时，必须使用本技能：
- 用户从「剪映SRT字幕导出」点击【📋 复制文本】后，粘贴文本并发起请求：
  * “帮我校对这段剪映字幕”
  * “这是刚导出的字幕文本，帮我校正并编辑样式”
- 斜杠命令：`/jianying-subtitle-optimizer [附带台词文本]`
- （兼容模式）：用户未粘贴文本时说“校对剪映最新草稿”，智能体通过本地 MCP 自动探测最新草稿。

---

## 📋 执行 SOP（核心四步）

### 第一步：获取字幕文本（用户直接粘贴）

1. **主流标准模式（用户主导，1秒完成，零冲突风险）**：
   - 用户打开桌面上的 **`剪映SRT字幕导出`**；
   - 选中目标草稿，点击右下角 **【📋 复制文本】**；
   - 直接将整段台词粘贴在对话中发给智能体。
2. **自动探测模式（备用兜底）**：
   - 若用户未附带文本，调用本地 MCP 工具 `get_latest_draft_subtitles` 自动定位最新草稿并提取字幕。

---

### 第二步：智能校对与纠错铁律

智能体对字幕逐句进行专业校准，严格遵循四大规则：

1. **【铁律】严格 1 对 1 行数对齐（总行数绝对守恒）**：
   - 校对后的列表长度必须与原文本行数完全相等（`len(corrected_lines) == len(lines)`）；
   - **严禁擅自合并行或跨行拆分**，确保每一行对应剪映时间轴上的一个独立字幕切片！
2. **清除口语废话与结巴卡顿**：
   - 彻底剔除“这个呃”、“然后呢”、“啊”、“那额度了”、“嗯”、“诶”等口语碎词，保持呼吸感与节奏感。
3. **专有名词与技术模型专业校准（结合本机事实）**：
   - `Claude open 十五点五` / `OPPO S5.5` ➔ **Claude Opus 5.5**
   - `GPT6.1SO` ➔ **GPT-6.1-Sol**
   - `workbody的H3` ➔ **WorkBuddy 的 Hy3**
   - `GPT plus` / `Claude的Pro` ➔ **ChatGPT Plus** / **Claude Pro**
   - 专业工具正字：`FocuSee`、`OpenFilm`、`FaceFusion`、`overlay-studio` 等。
4. **语法倒错纠偏**：
   - 修正“审美了很好” ➔ “审美非常好”、“我给他建议” ➔ “我给大家的建议”。

---

### 第三步：调整字幕样式与音量标准（克制、高保真、杜绝花里胡哨）

在写回剪映时，以**用户舒适阅读的「纯净基础字幕」为默认标准**，杜绝过度包装：

#### 1. 核心铁律：用户逐字稿 100% 守恒
- **严禁擅自拆分或合并用户的句子**：用户提前录制并对齐好的逐字稿，每一句都对应特定的节奏与镜头，严禁私自将单句拆碎。
- **默认单层基础字幕**：未经用户明确要求，**严禁私自叠加胸前重点大字、头顶标题轨或背景音效轨**，保持口播视频的自然纯净。

#### 2. 基础字幕黄金排版规范（Aa研宋体经典阴影 + 句内放大高亮）
| 属性 | 标准参数 | 为什么这么定 |
|---|---|---|
| **字体** | **Aa研宋体** (`7130644288047682085`) | 文化感、高级感，笔画纤细有力，耐看且不落俗套。 |
| **普通文字字号** | **`13.0`** | 竖屏手机阅读的黄金尺寸，不大不小，绝不挤压画面两边。 |
| **文字颜色** | 纯白（`#FFFFFF`） | 纯净通透。 |
| **标点符号铁律** | **彻底删除所有标点符号** | 杜绝句末逗号句号；较短停顿用单个**空格**隔开。 |
| **长句分行规则** | **中间按回车换行（`\n`）** | 长句子（> 10 字）在语意停顿处直接插入 `\n` 换行，**严禁切碎时间轴**，在同一字幕块内自然折成两行呈现。 |
| **重点词强调** | • **字号显著放大至 `16.5`**<br>• **文字加粗 (`bold = True`)**<br>• **高饱和亮金黄 (`[1.0, 0.88, 0.15]`)** | **【核心交付标准】** 在同一个字幕片段内实现主次分明，重点词瞬间聚焦跳出，既不遮挡博主面部，又有极强视觉冲击力！ |
| **阴影参数** | • 透明度：`60%` (`alpha = 0.6`)<br>• 模糊度：`6%` (`0.010`)<br>• 距离：`6.0`<br>• 角度：`-60.0°` | 无论博主穿白衣服、浅色衣服还是背景杂乱，文字立刻立体浮现，100% 保证清晰识别。 |
| **画面位置** | `y = -0.68` | 稳稳落在底部黄金安全区，不压底、不挡人像衣服与口型。 |

#### 3. 人声音频标准（标准广播级响度 +7.0 dB）
- **人声基础音量**：自动默认设为 **`+7.0 dB`**（底层线性增益 `volume = 2.2387`，不大不小刚刚好，整体波峰不超 6dB，绝不过曝且人声饱满清晰）；
- **免手动微调**：MCP 底层自动固化 `+7.0 dB` 标准参数写入工程，用户无需手动在剪映中逐个拖动音频滑杆。

#### 4. 高阶视觉包装规范（⚠️ 仅当用户明确要求时开启，且必须避开人脸）
若用户明确要求“加胸前重点词”或“加头顶标题”，严格遵守以下避坑红线：
- **胸前重点词必须位于衣领下方 (`y = -0.36`)**：**严禁放在 `y = -0.05`！** 竖屏自拍人脸往往占屏幕中上半部，放在 `-0.05` 会直接遮挡主播的嘴唇与下巴！必须下压至 `-0.36` 衣服拉链处；
- **头顶标题必须极简单行 (`<= 10 字`, `字号 <= 12.0`, `y = 0.82`)**：严禁长句子，严禁换行折成多行；
- **底色色块必须设置 check_flag |= 16**：确保剪映正常渲染背景色块。
根据重点词语义、情绪冲击力与镜头节奏，选择以下 10 种高级动效与音效搭配：

| 组合编号 | 重点词动画组合 | 搭配音效搜索词 | 典型情绪与适用场景 |
|---|---|---|---|
| **组合 01** | **向右缓入** + 蒙版 + 位置关键帧 | **回忆“刷”** / **出剑** | 核心观点亮剑、专业结论揭示 |
| **组合 02** | **随机飞入** + 蒙版向右滑动 | **旋风** / **铅笔在纸上画线写字** | 知识点推导、要点罗列 |
| **组合 03** | **向下溶解** + 缩放关键帧 | **尴尬转场** / **off** | 痛点打破、反常识反转 |
| **组合 04** | **向右模糊 II** + 移动关键帧 | **高音闪光转场** / **Swish** | 灵感闪现、亮点高光时刻 |
| **组合 05** | **向左缓出** + 向右滑动 | **综艺滑稽吹风声** / **利刃出鞘** | 破除误区、犀利犀利吐槽 |
| **组合 06** | **二段缩放** + 镜面蒙版 + 向右模糊 | **快速拉拉链** / **轻声呼woosh转** | 极速层级展开、步骤剖析 |
| **组合 07** | **放大** + 滚入 | **唰** / **数据读出数字** / **叮（收银机）** | 成果展示、收益与核心价值感 |
| **组合 08** | **向下滑动** + 关键帧 | **嗖** / **装子弹** / **呼woosh转场** | 武器/工具登场、硬核功能亮相 |
| **组合 09** | **缩小** + 关键帧 + 放大 | **盖章** / **综艺-咚咚** | 权威定论、敲黑板重点定格 |
| **组合 10** | **向下滑动** + 滚入 + 关键帧 | **嗖嗖** / **叮收银提示音1** | 总结升华、行动号召 |
#### 3. 人声音频标准（标准广播级响度 +7.0 dB）

根据专业口播剪辑调音规范，技能在写回剪映时，自动对视频/音频轨道进行标准化增益：
- **人声基础音量**：自动默认设为 **`+7.0 dB`**（底层线性增益 `volume = 2.2387`，不大不小刚刚好，整体波峰不超 6dB，绝不过曝且人声饱满清晰）；
- **背景音乐标准**（若有 BGM）：自动压至 **`-20 dB ~ -12 dB`**（约 `volume = 0.1 ~ 0.25`），确保人声前景突出；
- **免手动微调**：MCP 底层自动固化 `+7.0 dB` 标准参数写入工程，用户无需手动在剪映中逐个拖动音频滑杆。
